# Tennis paired avatar release

Sixteen reviewed transparent portraits cover Bronze through Unreal. Junior faces mature through adult tiers; playing, walking, leadership, celebration and awards poses distinguish the progression. Both appearances have equal kit and award prestige. Full prompts, references and SHA256 records are in tennis-production-record.json.

Tennis has no legacy collection: the ready male portrait is the default until an appearance is chosen. Both variants share the existing logical reward, thresholds and XP. The additive migration preserves owner/unlock checks, sanitized group identity and unchanged selection history. Rollback-only SQL covers ownership, unlock, persistence, group synchronization and plan/XP/history invariance.
