# Fencing paired avatar release

Sixteen reviewed transparent epee-inspired fencing portraits cover Bronze through Unreal. Both fictional identities progress from junior to mature adult with distinct introduction, recognition, ready, walking, leadership, celebration, award-group and formal poses. Both appearances have equal kit and award prestige. Silver received a targeted pose correction; Diamond received mask-placement corrections to show both shoes. Full prompts, references and SHA256 records are in fencing-production-record.json.

Fencing has no legacy collection: male artwork is the default until an appearance is chosen. Both appearances share existing logical rewards, thresholds and XP. The additive migration preserves ownership, unlock validation, sanitized group identity and unchanged selection history. Rollback-only SQL checks persistence, permissions and unchanged plan/XP/history.
