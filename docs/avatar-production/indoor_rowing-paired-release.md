# Indoor Rowing paired avatar release

Sixteen original transparent portraits cover male and female appearances for all eight tiers. Age progresses from juniors to mature adults with tier-specific poses, kit and awards. Indoor equipment uses connected handles and chains; the later award portraits omit the machine. Unreal uses an original flywheel honour. These illustrations do not claim official sporting titles.

The existing logical unlock supplies both appearances without additional XP or claim rewards. Original prompts, corrections, references, dimensions and SHA-256 are preserved in indoor_rowing-production-record.json.

Release checks include original RGBA/alpha/dimensions/hash validation, the full UTC application suite and build, rollback-only SQL ownership/unlock/sanitisation/group-sync/complete history and XP invariance checks, CI and Vercel preview before merge, then production hashes.
