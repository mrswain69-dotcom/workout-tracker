## Routing and release requirements

Activate each sport only with complete artwork and tested client/RPC allowlists. Running includes road, track and trail; Cycling includes road, leisure and indoor; Swimming includes pool/open water; Climbing includes bouldering/roped. Hiking requires explicitly logged hiking, not every walk. Strength requires actual logged training; no empty plans. Maximum one counted session per sport/day, excluding future, cancelled and recovery-suspended blocks. Padel/pickleball/table tennis must not match tennis through substring routing. Boxing and Pilates currently alias broad Martial Arts/Yoga: preserve existing claims and establish prospective explicit routing before release. Existing pace/distance badges and XP packs remain separate.
