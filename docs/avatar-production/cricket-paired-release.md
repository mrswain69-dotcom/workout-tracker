# Cricket paired avatar release

Sixteen transparent portraits cover Bronze through Unreal with equal male/female prestige, visible junior-to-adult ageing and varied recognition, batting, walking, captain, celebration and formal poses. Original legacy portraits remain available.

Appearance uses the existing paired_v2 metadata and unchanged logical reward keys, thresholds and XP. The additive RPC migration enables only the completed Cricket collection and preserves owner/unlock validation, sanitized group sync and history. Rollback-only database tests verify these invariants. Prompts, references, alpha validation and SHA256 records are in cricket-production-record.json.
