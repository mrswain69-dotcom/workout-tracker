# Basketball paired avatar release

Sixteen transparent portraits cover Bronze through Unreal, with junior-to-adult faces, varied poses and equal male/female kit and award quality. Prompts, references and SHA256 records are retained in basketball-production-record.json.

Basketball has no legacy collection: valid male artwork is the default until an appearance is chosen. Both variants share the same reward identity, XP and unlocks. The additive migration extends existing owner/unlock-checked appearance saving without splitting history. Rollback-only SQL checks cover permission, unlock, persistence, sanitised group sync and unchanged plan/XP/history.
