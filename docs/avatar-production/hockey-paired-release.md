# Hockey paired avatar release

Sixteen reviewed transparent field-hockey portraits cover Bronze through Unreal. Auburn-haired, green-eyed fictional identities progress from junior to mature adult, with introduction, recognition, playing, walking, leadership, celebration, trophy-group and formal poses. Both appearances have equal kit and award prestige. Equipment is field hockey throughout. Full prompts, references and SHA256 records are in hockey-production-record.json.

Hockey has no legacy collection: male artwork is the default until an appearance is chosen. Both appearances share existing logical rewards, thresholds and XP. The additive migration preserves ownership, unlock validation, sanitized group identity and unchanged selection history. Rollback-only SQL checks persistence, permissions and unchanged plan/XP/history.
